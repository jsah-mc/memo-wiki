Installing Memo is easy! Follow the steps below to get started.

## Memo CLI (Mandatory)

So To install Memo Run The Folowing Command For Your OS In the Terminal:

<Tabs>
  <TabItem label="Windows">
    ```
    irm https://memobot.us.ci/installwin | iex
    ```
  </TabItem>
  <TabItem label="MacOS & Linux">
   ```
    curl -fsSL https://memobot.us.ci/install | bash
   ```
  </TabItem>
</Tabs>

And Thats All You Need To Do! You Can Now Run Memo By Typing `memo` In The Terminal.

## Memo Desktop

Memo Usally comes only in a cli but if you want to run Memo Desktop you can run the following command in the terminal:

```
memo desktop
```
