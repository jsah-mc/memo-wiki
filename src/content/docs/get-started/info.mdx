## What is Memo?
Memo Is A Open Source Grok Bot Alternative That Can Be Used With A Widespread of AI agents.

## Supported Agents
Memo Supports A Widespread Of AI Agents Including:
- Codex
- Claude Code
- Antigravity
- Opencode
- Grok Build
- Ollama
- Hermes
- PI
- LM Studio
